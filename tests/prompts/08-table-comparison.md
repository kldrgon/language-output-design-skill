# 08 表格比较

## 评测目标

三组方法共享同一组指标，应使用表格便于沿列比较。表格前后要用段落说明差异是否有实际意义；缺失项要标出来。不要只堆最优数字，也不要把因果解释压进优缺点格子。

## 输入

请根据下面实验结果，帮我判断该上哪一种检索方法。读者需要快速对比数字，也需要知道差异值不值得换方案。

基线：召回率 71.4%，平均延迟 38 ms，重复 5 次。  
方法 A：召回率 74.1%，平均延迟 81 ms，重复 5 次。  
方法 B：召回率 73.8%，平均延迟 41 ms，重复 5 次。  
方法 C 的召回率没有记录，平均延迟 36 ms，重复 5 次。

指标都是越高召回越好、延迟越低越好。当前线上可以接受大约 50 ms 以内的延迟。
