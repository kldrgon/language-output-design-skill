# 语篇主线与关系流

## 完成当前关系

每段先完成一个主要意图，再进入下一段。主句尚未闭合时，不沿其中一个术语继续解释其子概念。

判断支线是否应立即展开。省略支线不会改变当前结论时，把它放到主线之后；支线会改变结论或涉及危险时，立即说明并标记其作用。

## 让下一段成为必要

段落之间不应只是主题相关，还应形成可说明的关系。

- 上一段提出原因，下一段说明结果
- 上一段建立通则，下一段说明边界
- 上一段给出判断，下一段提供证据
- 上一段描述现象，下一段提出验证
- 上一段建立机制，下一段展示应用

如果多个段落可以任意交换且读者察觉不到，文本可能只是内容列表。重新确定段落间的依赖关系。

## 标记话题变化

切换层级或范围时，说明变化类型，例如“回到当前实现”“这个限制只影响远程部署”“先完成读取流程，再看更新流程”。

不要机械添加连接词。连接词应命名真实关系；无法说清关系时，先检查两段是否应当相邻。

## 处理支线

需要短暂展开时，先说明支线为什么影响主线，支线结束后明确返回。不要依靠长括号和多层破折号维持支线。
