# 组织方法索引

按当前写作问题读取，不要一次加载全部文件。

- 不知道从哪里讲起或怎样排序时，读取 [entry-and-order.md](entry-and-order.md)
- 段落各自通顺但整体跳跃时，读取 [discourse-flow.md](discourse-flow.md)
- 出现先否定后肯定、过早勘误或装饰性对比时，读取 [corrections-and-contrast.md](corrections-and-contrast.md)
- 不知道限制和例外应放在哪里时，读取 [limits-and-exceptions.md](limits-and-exceptions.md)
- 语气生硬、中性化或场景不匹配时，读取 [register-and-tone.md](register-and-tone.md)
- 列表、标题、段落或层级选择不当时，读取 [lists-and-format.md](lists-and-format.md)
- 多个对象需要按共同维度比较时，读取 [tables-and-comparisons.md](tables-and-comparisons.md)
- 需要设计示例或类比时，读取 [examples-and-analogies.md](examples-and-analogies.md)

需要完整案例时，再从 [../examples/INDEX.md](../examples/INDEX.md) 进入对应案例。
