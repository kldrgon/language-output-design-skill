# 基础判断索引

只读取当前任务需要的文件。

- 不确定受众能力、交流条件或所需深度时，读取 [audience-and-context.md](audience-and-context.md)
- 不确定内容属于解释、步骤、参考、诊断还是建议时，读取 [knowledge-types.md](knowledge-types.md)
- 内容复杂、受众容易过载或新手与熟手需要不同指导时，读取 [cognitive-load.md](cognitive-load.md)
- 需要理解原则来源、适用边界或避免过度概括时，读取 [research-basis.md](research-basis.md)

完成基础判断后，返回 `SKILL.md` 继续核心流程。不要因为读取基础资料而提前展开正文。
