# 基础判断索引

只读取当前任务需要的文件。

- 要按受众已有知识和交流条件调整深度时，读取 [audience-and-context.md](audience-and-context.md)
- 否定缺少对应预期、叮嘱只对部分人有用、或指令默认听众正在做某件事时，读取 [grounding-and-relevance.md](grounding-and-relevance.md)
- 要按解释、步骤、参考、诊断或建议来组织内容时，读取 [knowledge-types.md](knowledge-types.md)
- 内容复杂、容易过载，或新手与熟手需要不同指导时，读取 [cognitive-load.md](cognitive-load.md)
- 要核对原则来源、适用边界或避免过度概括时，读取 [research-basis.md](research-basis.md)

完成基础判断后，返回 `SKILL.md` 继续核心流程。不要因为读取基础资料而提前展开正文。
