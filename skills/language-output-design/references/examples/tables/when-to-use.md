# 表格使用案例

## 适合表格的比较

**场景**  
在实验报告中比较三种方法的准确率和延迟。读者需要快速判断哪种方法在特定条件下更优。

**原文**

> 方法 A 的准确率是 92.0%，延迟是 61 ms。方法 B 的准确率是 91.8%，延迟是 43 ms。基线的准确率是 91.2%，延迟是 48 ms。

**问题**  
段落形式需要读者自行提取和比较数值，增加认知负担。

**改写**

| 方法 | 准确率 | 平均延迟 | 重复次数 |
| --- | ---: | ---: | ---: |
| 基线 | 91.2% | 48 ms | 5 |
| 方法 A | 92.0% | 61 ms | 5 |
| 方法 B | 91.8% | 43 ms | 5 |

**改写依据**  
表格使读者能够沿列直接比较共同指标，减少在段落中寻找对应项的负担。

## 不适合表格的比较

**场景**  
在技术文章中解释为什么某个设计决策在特定条件下更优。读者需要理解因果关系，而不是比较数值。

**原文**

| 方案 | 优点 | 缺点 |
| --- | --- | --- |
| 方案 A | 简单 | 性能低 |
| 方案 B | 性能高 | 复杂 |

**问题**  
表格把复杂的因果关系压缩成对称的优缺点，无法说明条件如何改变结论。

**改写**

> 当前团队规模较小，模块之间需要频繁事务，并且没有独立部署需求，方案 A 的协调成本更低。只有模块出现独立扩缩容、发布节奏或故障隔离需求时，再评估方案 B。

**改写依据**  
当信息需要连续建立因果关系时，段落比表格更合适。

## 缺失数据标记

**场景**  
在实验报告中比较三种方法的性能。其中一种方法没有测量延迟。

**原文**

| 方法 | 准确率 | 延迟 |
| --- | ---: | ---: |
| 基线 | 91.2% | 48 ms |
| 方法 A | 92.0% | 61 ms |
| 方法 B | 91.8% | |

**问题**  
空白单元格可能表示“未测量”“不适用”或“数据缺失”，读者无法判断。

**改写**

| 方法 | 准确率 | 延迟 |
| --- | ---: | ---: |
| 基线 | 91.2% | 48 ms |
| 方法 A | 92.0% | 61 ms |
| 方法 B | 91.8% | 未测量 |

**改写依据**  
明确标记缺失数据，避免读者猜测空白单元格的含义。
