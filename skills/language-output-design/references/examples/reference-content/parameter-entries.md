# 参考内容案例

## 参数条目缺少字段

**场景**  
在 API 文档中说明 `timeout` 参数。读者需要快速判断该参数是否必需、默认值是什么，以及如何验证设置生效。

**原文**

> `timeout` 参数用于控制请求超时。

**问题**  
只给出用途，没有说明类型、默认值、是否必需或验证方式。读者需要额外查找信息才能使用。

**改写**

> `timeout`  
> 类型：整数，单位毫秒  
> 是否必需：否  
> 默认值：5000  
> 作用：控制请求等待响应的最长时间  
> 限制：取值范围为 100 到 30000  
> 最小示例：`timeout: 10000`

**改写依据**  
参数条目使用一致字段，使读者能够快速定位、比较和复用事实。

## 错误码说明不完整

**场景**  
在错误码参考中说明 `403` 的含义。读者需要知道如何区分权限不足和令牌失效。

**原文**

> `403` 表示禁止访问。

**问题**  
没有说明常见原因、排查步骤或相关错误码的区别。

**改写**

> `403 Forbidden`  
> 含义：服务器理解请求，但拒绝执行  
> 常见原因：令牌权限不足、资源策略禁止访问、IP 白名单限制  
> 排查步骤：检查令牌权限、确认资源策略、核对 IP 白名单  
> 相关错误码：`401` 表示未认证，`403` 表示已认证但无权限

**改写依据**  
错误码条目包含含义、原因、排查步骤和对比，帮助读者快速定位问题。

## 版本差异没有比较

**场景**  
在迁移指南中说明两个版本的配置差异。读者需要知道哪些字段被重命名、删除或新增。

**原文**

> v2 版本对配置进行了调整，请查阅文档。

**问题**  
没有给出具体差异，读者需要自行比对两个版本的文档。

**改写**

| 字段 | v1 | v2 | 说明 |
| --- | --- | --- | --- |
| `timeout` | 支持 | 支持 | 单位从秒改为毫秒 |
| `retry_count` | 支持 | 已删除 | 改用 `retry.attempts` |
| `retry.attempts` | 不支持 | 支持 | 新增嵌套配置 |

**改写依据**  
表格使版本差异可快速扫描，并说明每个字段的变化类型。
