# 教程与操作指导

## 先区分教程和操作指南

教程面向正在建立能力的人，通过一个受控任务完成学习。操作指南面向已有基础的人，帮助其解决具体问题。

教程需要更多前置说明、中间结果和解释。操作指南应更快到达目标，并假设读者理解基础环境。

## 组织流程

先说明目标、适用条件和完成后的可观察结果。列出真正会阻断执行的前置条件，不列与当前任务无关的背景。

步骤按真实执行顺序排列。每一步以明确动作开头，只承担一个主要动作。必要解释、命令和预期结果紧邻该步骤。

正常路径先完成，再处理常见失败分支。会造成不可逆后果的风险必须放在危险动作之前。

最后给出验证方法，使读者能够判断任务是否真正完成。

## 避免

不要在步骤中间插入完整原理课程。不要只写命令而省略执行位置、输入来源或成功信号。不要把多个可独立失败的动作塞进同一步。不要把警告放在执行之后。
