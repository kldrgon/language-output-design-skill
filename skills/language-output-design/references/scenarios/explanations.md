# 概念与原理解释

## 目标

让受众形成可迁移的关系模型，而不只是记住定义、术语或步骤。

## 组织流程

先识别受众缺少的关系，再从现象、问题、机制、必要定义或结构清晰的例子中选择一个认知支点。

建立核心模型时，说明以下关系。

- 涉及哪些对象
- 对象之间有什么关系
- 哪个条件触发变化
- 状态如何变化
- 为什么得到当前结果
- 结论在哪些范围内成立

随后用例子显示模型怎样运行。例子之后把具体对象重新映射到一般关系。

需要迁移时，增加第二个表面不同但结构相同的案例，或加入边界反例。最后根据受众能力决定是否要求复述、预测或应用。

## 避免

不要从孤立定义开始后立即堆术语。不要只给操作步骤却不说明步骤解决了什么关系。不要用类比代替目标机制。不要在核心模型尚未建立时集中讲误区。

## 验证

好的解释应让受众能够回答以下问题。

- 哪些对象在发生作用
- 条件改变时结果为什么会变
- 相同规则能否用于另一个案例
- 哪些情况超出解释范围
