# 场景索引

根据当前主要任务读取一个场景文件。一个输出同时承担多种任务时，先确定主任务，再只读取必要的辅助场景。

- 学习概念、原理或设计原因时，读取 [explanations.md](explanations.md)
- 完成具体操作或编写教程时，读取 [procedures.md](procedures.md)
- 编写参数、API、规格或查阅内容时，读取 [reference-content.md](reference-content.md)
- 排查错误、性能或异常行为时，读取 [diagnostics.md](diagnostics.md)
- 比较方案并提出建议时，读取 [decisions.md](decisions.md)
- 审阅、改写或清理已有文本时，读取 [rewriting.md](rewriting.md)

场景文件说明组织流程；正反例从 [../examples/INDEX.md](../examples/INDEX.md) 按需读取。
