# 参考资料

## 目标

让读者快速定位、比较和复用事实，不要求从头到尾阅读。

## 组织方式

按读者实际查找方式分组，例如功能、对象、命令、参数或错误码。每类条目使用一致字段，但不要为了形式统一填充无意义内容。

参数条目通常包含以下字段。

- 名称
- 类型或格式
- 是否必需
- 默认值
- 作用
- 限制
- 最小示例

命令条目通常包含用途、语法、关键选项、输出和退出状态。API 条目通常包含请求、响应、错误和权限要求。

## 写作要求

事实应可验证，术语应稳定。重要限制放在对应条目附近，不要统一藏在页面末尾。示例保持最小，只展示该条目的典型用法。

不要把参考条目写成连续教程，也不要在每个参数下重复完整背景。需要解释设计原因时，链接到解释内容。

## 验证

随机选择一个事实，确认读者可通过标题和字段快速找到。检查相同类型条目是否使用相同术语与单位。
