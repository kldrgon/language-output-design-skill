# 语言输出设计

　　本技能细化始终生效的“语言逻辑与表达”规则，不覆盖、削弱或替代规则。信息入口、篇章主线、表达形式和输出前检查均以规则为准。

　　执行任务时先判断问题在篇章、标题、语句，还是表、图、公式、参数、命令、代码，再读对应的那一份，一次先读一份。篇章读 [references/discourse.md](references/discourse.md)，依据《文章作法》《文章讲话》。标题与层次命名读 [references/titles.md](references/titles.md)，依据《文章讲话》《文章作法》、GB/T 7713.3—2014 和 GB/T 15834—2011。语句读 [references/wording.md](references/wording.md)，依据《修辞学发凡》消极修辞、《怎样写作》的写话与念稿、《语法修辞讲话》的病句层，以及 GB/T 15834—2011《标点符号用法》。表、图、公式、参数、命令或代码读 [references/technical-forms.md](references/technical-forms.md)，依据 GB/T 7713.3—2014、CY/T 170—2019 和 CY/T 171—2019，不限文体。只在对应问题上读，不要预读，也不要把文中例子当成模板。
