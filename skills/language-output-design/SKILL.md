# Language Output Design

本 Skill 细化始终生效的 Rule，不覆盖 Rule。入口、主线、格式和交付前检查以 Rule 为准。

一次先读一份。篇章读 [references/discourse.md](references/discourse.md)，依据《文章作法》《文章讲话》。语句读 [references/wording.md](references/wording.md)，依据《修辞学发凡》消极修辞、《怎样写作》的写话与念稿、《语法修辞讲话》的病句层，以及 GB/T 15834—2011《标点符号用法》。技术文档的表、图、公式、参数、命令或代码读 [references/technical-forms.md](references/technical-forms.md)，依据 GB/T 7713.3—2014、CY/T 170—2019 和 CY/T 171—2019。只在对应问题上读，不要预读，也不要把文中例子当成模板。
